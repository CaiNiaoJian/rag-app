# 开发文档 —— Windows RAG 文档数据工厂

> 文档版本：v1.0（2026-07）· 适用范围：V1「文档数据工厂」开发全周期，V2 为方向性规划
> 产品代号：**DocFactory**（正式名待定）

## 这是什么

一个**完全离线**的 Windows 桌面应用：导入杂乱的 doc / docx / pdf / ppt / pptx / xls / xlsx 文档，深度解析为结构完整的 Markdown / 中间表示（IR），结构感知切片后导出为 MD / PDF / JSON / CSV / 微调数据集（Alpaca、ShareGPT），服务于 RAG 与模型微调数据生产。核心卖点：**复杂文档解析的内容完整性**——版面分析、表格结构还原、质量量化、降级透明。

## 阅读指引

- **契约优先**：本文档的 IR Schema（04）、SQLite schema（02）、.kmod 格式与模型接口（06）、错误码注册表（07）是**跨模块冻结契约**，改动需评审并升版本号；其余章节为实现指导，可在里程碑内迭代。
- **一致性规则**：全文档技术裁决以 01 章 §1.5「关键技术决策总表」为唯一事实来源，任何章节与其冲突时以总表为准并提 issue 修正。
- 2 人团队按里程碑（08 章）推进：一人主前端 + 打包，一人主解析引擎，契约章节共同评审。

## 硬约束（不可协商）

1. 运行时**完全离线**，禁止任何外联（本机 127.0.0.1 回环除外）。
2. 安装即用：除安装包自带内容外，不要求用户安装 Python、Office、任何运行库。
3. 仅 Windows 10/11 x64。
4. 闭源商用分发：**禁止引入 GPL/AGPL 依赖**（详见 03 章许可证审查）。
