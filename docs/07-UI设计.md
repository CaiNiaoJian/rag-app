# 07 · UI 设计

目标用户为非技术人员：**主流程零配置、页面克制、失败可解释**。

## 1. 信息架构（六页，冻结）

左侧固定图标导航（56px，可展开），顶部窄工具条（全局搜索 + 引擎状态灯）。

| 页面 | 内容 |
|---|---|
| **1 工作台**（默认页） | 上半：常驻拖拽导入区（文件/文件夹/多选，或点击选择；拖入时自动识别类型并弹确认清单，标出不支持项）。下半：任务队列——文件名、类型图标、状态（排队/解析中/成功/警告/失败）、进度条、耗时；行操作：重试/取消；队列级：暂停/继续。导入即建任务不跳页 |
| **2 文档库** | 已处理文档列表（按类型/状态/时间筛选、搜索）。双击进**解析预览**（核心卖点载体）：左栏 IR 结构树（章节/表格/图片节点，点击定位）、中栏原文（PDF 逐页渲染，Office 用解析期页快照 preview/p{n}.png）、右栏 Markdown 渲染；中右滚动联动；切片边界高亮、低置信区域黄色高亮；顶部显示完整性指标（覆盖率/表格置信度/解析级别） |
| **3 导出中心** | 三栏：左范围（单文件/勾选批量/「仅成功」过滤）→ 中格式（六种，05 章）→ 右参数（切片参数触发重切、页眉页脚、数据集选项）。导出进队列，完成「打开所在文件夹」 |
| **4 仪表盘** | 指标卡片 + 图表，见 §3 |
| **5 日志** | 时间倒序，级别筛选（信息/警告/错误）、按文件名/任务搜索、点击定位关联任务、「导出诊断包」zip |
| **6 设置** | Tab：通用（输出目录/并行数/OCR 开关）、高级（降级策略/超时/切片默认值）、模组管理（已装模组列表：名称/类型/版本/回滚按钮 + 「导入离线更新包」）、模型接口（V1 置灰占位 + V2 能力说明）、关于（版本/第三方声明/数据目录位置） |

交互约定：任务/文档详情用**右侧抽屉**（不打断队列视图），不用弹窗；空状态用插画 + 「把文件拖到这里」；首启仅 3 步气泡引导，无强制向导。

## 2. 核心用户流

**A. 批量解析→导出**：拖 20 个杂乱文件→确认清单（标出 2 个不支持）→开始解析→队列并行+托盘通知→「17 成功 / 2 警告 / 1 失败」→文档库抽查三栏对照→全选导出 Markdown→打开文件夹。

**B. 失败定位**：失败行红色 + 一句话原因（「文件被密码保护」）→点击展开右侧抽屉：阶段时间线（读取→转换→版面分析→OCR→切片，标出失败步骤）+ 人话文案 + 建议操作 + 「查看技术详情」折叠（错误码/栈摘要/相关日志 50 行）+ 「复制诊断信息」「在日志中查看」→处理后一键重试。

**C. 离线模组更新**：联网机下载 .kmod 拷入→拖到任意界面→识别为模组包→展示「高精度 OCR v2.1→v2.3 + 更新说明」→确认→验签安装→提示重启引擎→列表刷新版本，日志记录事件；失败自动回滚并提示原因。

**D.（V2 预留）本地模型生成 Q&A**：导入 llm-runtime + GGUF 模型 .kmod→设置启用→导出中心解锁「Q&A 数据集（模型生成）」→选范围与参数（每切片问答数/语言）→后台任务→产出 Alpaca/ShareGPT，预览抽查。

## 3. 仪表盘指标（数据来源即 02 章 schema）

| 指标 | 展示 | 来源 |
|---|---|---|
| 导入文件数 / 类型分布 | 数字卡 + 饼图（累计与近 7 日） | metrics_daily + documents GROUP BY fmt |
| 解析成功率 | 环形图（ok/warning/failed 三态） | documents.status 聚合 |
| **解析分级占比** | 堆叠条（L0/L1/L2 页占比，卖点指标） | documents.parse_level + degraded_pages |
| **平均文本覆盖率** | 数字卡 + 趋势线（卖点指标） | documents.text_coverage 均值 |
| 切片分布 | 每文档切片数 / 长度直方图 | chunks 聚合 |
| 失败原因 TOP5 | 条形图，点击跳日志 | task_events WHERE level='error' GROUP BY code |
| 处理耗时 | 平均/中位（按类型分组） | tasks 时间差 |
| OCR 触发占比 | 数字卡 | metrics_daily.ocr_pages |

趋势类走 metrics_daily 预聚合；明细类实时聚合（02 章 §4）。

## 4. 错误码注册表（E01~E07，全局唯一事实来源）

同时服务：UI 文案映射、失败 TOP 统计、日志检索、用户手册。

| 码 | 场景 | 用户文案 | 建议操作 | 技术详情记录 |
|---|---|---|---|---|
| E01 | 文件损坏/无法打开 | 文件似乎已损坏，无法读取 | 用原程序打开确认后重新导入 | 解析器异常栈 |
| E02 | 密码保护 | 文件受密码保护 | 先在原程序中解除密码再导入 | 加密标志位 |
| E03 | 格式不支持/转换失败 | 暂不支持此文件格式（或旧格式转换失败） | 查看支持格式清单；旧格式可另存为新格式后导入 | LibreOffice 退出码/超时记录 |
| E04 | OCR 低置信（**警告**非失败） | 扫描质量较低，部分文字可能识别不准 | 预览中检查黄色高亮区域；可尝试高精度 OCR 模组 | 页均置信值 |
| E05 | 内容为空/截断 | 未能提取到有效内容（或超大表已截断） | 确认文件内容；超大表建议拆分 | 提取字符数/截断行数 |
| E06 | 引擎超时/崩溃 | 处理超时或引擎异常，已自动重试 | 重试；反复出现请导出诊断包反馈 | 栈/重启记录/阶段耗时 |
| E07 | 磁盘空间不足 | 磁盘空间不足，无法继续 | 清理磁盘或在设置中迁移数据目录 | 需求/可用空间 |

降级事件 `DGR-L1 / DGR-L2` 记 warning 级 task_events（03 章 §5），不占用 E 码。

## 5. 风格基调

浅色为主（白底 + 浅灰分区），单一品牌蓝强调，绿/黄/红状态色克制使用；字体 Segoe UI / 微软雅黑；桌面工具紧凑密度（非网页留白风）。竞品教训：借鉴 MinerU「拖入即解析」极简主线；规避 AnythingLLM「隐性前置配置卡住小白」——所有默认值即最佳实践，专家参数收「高级」折叠；把「失败可解释」（错误分级 + 阶段时间线）做成差异点。
