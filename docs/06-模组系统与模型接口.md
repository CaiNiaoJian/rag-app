# 06 · 模组系统（.kmod）与本地模型接口

## 1. .kmod 包格式（冻结契约）

`.kmod` = 重命名的 zip 包，任意界面拖入即识别。结构：

```
manifest.json      # 元数据（见下）
signature.bin      # Ed25519 签名（对 manifest.json 规范化字节签名）
payload/           # 模组内容（模型文件/组件/GGUF 等）
```

```json
{
  "manifest_version": 1,
  "id": "ocr-server-zh",
  "name": "高精度 OCR 模型包（中英）",
  "type": "ocr",                       // parser | ocr | converter | llm-runtime | llm-model
  "version": "2.3.0",                  // semver
  "api_version": "1.x",                // 兼容的引擎模组 API 版本区间
  "min_app_version": "1.0.0",
  "files": [ { "path": "payload/det.onnx", "sha256": "…" } ],   // 逐文件哈希清单
  "changelog": "…", "size_bytes": 15300000
}
```

## 2. 安装 / 更新 / 回滚流程

```
拖入 .kmod → 复制到 staging\ → ①验签(Ed25519, 公钥编译进主程序)
→ ②逐文件 SHA-256 校验 → ③兼容性检查(api_version / min_app_version)
→ ④解包到 modules\{id}\{newVer}\（旧版本保留）
→ ⑤modules 表更新版本指针(prev_version=旧版) → ⑥提示重启引擎生效
→ ⑦引擎启动自检：加载失败 → 指针自动回滚 prev_version + UI 提示
```

- 任一步失败：清理 staging，报具体原因（签名无效/文件损坏/版本不兼容），**不影响现有版本**。
- V1 **不做热替换**（重启引擎生效，换取确定性）；UI 提供手动「回滚到上一版本」。
- 应用本体升级：分发**完整签名 NSIS 安装包**覆盖安装（用户数据目录不动，见 02 章 §5）；离线场景不做差分更新。

## 3. 签名工程（离线信任链的根）

| 项 | 规程 |
|---|---|
| .kmod 签名私钥 | 离线保管（不入库、不上 CI；密码保护 + 两处物理备份）；发布时人工在离线机上签名 |
| 公钥 | 编译进主程序；**预留公钥列表**（多公钥验证），轮换 = 新版本应用带新旧双公钥过渡 → 下下版移除旧钥 |
| 应用与安装包 | 代码签名证书（signtool）签 exe/安装包，降低杀软误报（08 章风险 9）；发布时同步公布安装包与 .kmod 的 SHA-256 清单供人工核验 |

## 4. 本地模型接口（V1 冻结契约，V2 实装）

### 4.1 对外契约：OpenAI-compatible REST

由 llm-runtime 模组在 `127.0.0.1:{modelPort}` 提供（未来即 llama.cpp `llama-server.exe` + 4B/8B GGUF 模型模组，零改造接入）：

- `GET /v1/models` — 已加载模型列表
- `POST /v1/chat/completions` — 标准 OpenAI 格式（messages / temperature / max_tokens / stream）

### 4.2 引擎内抽象：ModelProvider

```python
class ModelProvider(ABC):
    def capabilities(self) -> dict: ...      # {"chat": bool, "max_context": int, "model_id": str}
    def chat(self, messages: list[dict], **kw) -> str | Iterator[str]: ...
    def health(self) -> bool: ...

class NullProvider(ModelProvider):
    """V1 默认注册。所有调用返回明确错误码 MODEL_NOT_INSTALLED（UI 文案：未安装模型模组）。"""
```

- 引擎持 Provider 注册表；llm-runtime 模组安装后注册 `OpenAICompatProvider`（转发 127.0.0.1 模型服务）。
- socket guard 白名单放行该本地端口（02 章 §7）。

### 4.3 V1 需要落地的桩清单

1. `ModelProvider` 抽象 + `NullProvider` + 注册表。
2. 任务类型 `qa_generate`、`dataset_build` 的完整链路（V1 走留空模板/规则生成器，见 05 章 §3.3）——接入模型后仅替换生成器实现。
3. 引擎 `/v1/*` 代理端点（V1 返回 MODEL_NOT_INSTALLED）。
4. 设置页「模型接口」占位区（置灰 + V2 能力说明）。
5. Q&A 生成任务契约：输入 chunk（parent-child，04 章）→ 输出 Alpaca/ShareGPT 记录（05 章 schema）。
