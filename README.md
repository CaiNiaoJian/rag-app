# DocFactory

**完全离线的 Windows 文档数据工厂**

把杂乱的 Word / PDF / PPT / Excel 批量整理成干净、结构完整的数据，
用于搭建 RAG 知识库、准备大模型微调语料，或者单纯把老文档变成好用的 Markdown。

## 它能做什么

你把文档拖进来，它负责剩下的事：

1. **导入**：支持 `doc` `docx` `pdf` `ppt` `pptx` `xls` `xlsx` 七种格式，拖拽文件或整个文件夹即可，批量处理排队自动跑。
2. **解析**：把文档还原成结构完整的内容——标题层级、表格、图片、页码出处都保留，而不是一坨乱掉的纯文本。
3. **切片**：按语义结构自动切成适合检索的片段（表格不拦腰截断、标题跟着正文走），粒度可调。
4. **导出**：一键导出为 Markdown、PDF、JSON、CSV，或直接生成 Alpaca / ShareGPT 格式的微调数据集。

全程**不需要联网**，数据从头到尾不出你的电脑——适合内网、涉密或纯粹注重隐私的环境。

## 谁适合用

- 需要把单位里成百上千份历史文档整理成知识库的人
- 想给本地大模型喂料（RAG 语料、微调数据集）的人
- 不想配 Python、不想敲命令行、只想双击就能用的人

## 下载与安装

1. 前往 [Releases 页面](https://github.com/ohaoz/rag-app/releases/latest)，下载 `DocFactory-x.y.z-win-x64-setup.exe`
2. 双击安装包——**没有安装向导，不需要管理员权限**，几秒钟装完自动启动
3. 桌面和开始菜单会出现 DocFactory 快捷方式

> **首次运行提示**：当前版本尚未做代码签名，Windows SmartScreen 可能弹出「未知发布者」警告。
> 点「更多信息 → 仍要运行」即可。卸载时默认保留你已解析的数据。

**更新方式**：应用内「设置 → 关于 → 检查更新」，发现新版会引导你到下载页；不会在后台偷偷联网。

## 为什么是它

市面上的文档解析工具，遇到多栏 PDF、跨页大表、扫描件、旧版 Office 格式时，普遍会丢内容、丢结构，而且坏了也不告诉你哪儿坏了。DocFactory 的做法不一样：

| | 一般工具 | DocFactory |
|---|---|---|
| 解析失败 | 静默丢内容 | 三级降级链逐页兜底，每页用了哪一级都有记录 |
| 质量好坏 | 靠肉眼猜 | 每份文档给出文本覆盖率、表格置信度等量化指标 |
| 结果核对 | 自己开原文对 | 内置「原文 vs 解析结果」对照预览 |
| 报错 | 一串堆栈 | 人话文案 + 建议操作，技术详情折叠备查 |

## 当前版本状态

目前发布的是**早期预览版（v0.1.x）**，主链路已经可用：

- 导入 → 解析 → 切片 → 导出全流程跑通，批量任务队列、进度、取消、重试可用
- `docx` / `pptx` / `xlsx` / 文本型 PDF / `xls`（兜底转换）解析可用
- 六种导出格式可用；仪表盘、日志查看器、诊断包导出可用
- 完整性指标（文本覆盖率等）真实统计，不注水

以下能力在路线图上，尚未就绪：

- 深度版面分析（复杂多栏 PDF 的阅读顺序还原、跨页表合并）
- 扫描件 / 图片文字的离线 OCR
- 旧版 `doc` / `ppt` 的内置转换（当前这两种格式暂不可解析）
- 离线模组（.kmod）热更新、本地模型问答（V2 规划）

## 常见问题

**Q：真的完全离线吗？**
是。运行时禁止一切外联（代码层面强制，双进程都有网络闸），只用本机回环通信。「检查更新」也只在你手动点击时才访问 GitHub。

**Q：我的数据存在哪里？**
`%LOCALAPPDATA%\DocFactory`。卸载时默认保留，不会静默删除。

**Q：支持 macOS / Linux 吗？**
不支持，V1 只做 Windows。
